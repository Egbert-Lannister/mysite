Robust Spatial Learning for Everyday Robotics

This project investigates whether explicit spatial memory can help a robot generalize across rearranged kitchens, changing lighting, and unfamiliar objects. The approach combines calibrated observations with a compact scene representation that can be updated as the robot moves.

The study asks two questions: does the representation improve task completion, and which components contribute most to reliable recovery after a failed action?

Method

Observations pass through a geometry-aware encoder and are written into a local scene map. A policy then reasons over the map to select the next manipulation step. Training uses simulated rearrangements, while evaluation includes held-out real scenes. 

scene_map = encoder.update(observation, camera_pose)
action = policy.next_action(scene_map, task_goal)

Experiments

We compare against a frame-only policy and an ablation without map updates. Each configuration is evaluated on the same object placements with three random seeds.

Conclusion

Explicit spatial memory improved robustness in both simulated and real evaluations. The largest gains appeared when objects moved after the initial observation, suggesting that online updates—not additional visual features alone—drive most of the improvement.

Reliable embodied behavior requires a representation that can change when the world changes.
  • Evaluate broader object categories and longer task horizons.
  • Measure uncertainty explicitly before committing to an irreversible action.
  • Release evaluation layouts and episode definitions with the final artifacts.
